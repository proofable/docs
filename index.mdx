## Protect product access

Verify a person or account, then check the result on your server before granting access.

One check needs no gate. Send the person to Hosted Verify and read the proof:

```text
https://proofable.me/verify?verifiers=proof-of-human&returnUrl=https://app.example.com/callback
```

The `qHash` comes back in your callback. Your server checks it:

```ts
import { ProofableClient } from '@proofable/sdk';

const proofable = new ProofableClient();
const result = await proofable.gateCheck({
  gate: [{ verifierId: 'proof-of-human' }],
  subject: { accountId: user.accountAddress },
});

if (!result.satisfied) {
  // Send them to Hosted Verify, then check again.
  throw new Error('Verification required');
}

// Allow the action.
```

Reach for a published gate only when the decision needs several checks, a price, or a schedule. [Gates](/gates)

Your server allows or denies. Proofable returns the current result.
