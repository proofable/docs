## Protect your app

Verify a user or agent once. Check that result on your server.

```ts
import { ProofableClient, defineGate } from '@proofable/sdk';

const proofable = new ProofableClient();
const gate = defineGate([{ verifierId: 'proof-of-human' }]);
const result = await proofable.gateCheck({
  gate,
  subject: { accountId: user.accountAddress },
});

if (!result.satisfied) {
  // Show VerifyGate or Hosted Verify for result.missing, then check again.
  throw new Error('Verification required');
}

// Allow the action.
```

Your server allows or denies. Proofable returns the current result.
