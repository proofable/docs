## Connect an AI client

Add `https://mcp.proofable.me/mcp` to your AI client, click **Connect**, then ask:

> Show my Proofable profile and proofs.

Use the [one-click installer](https://proofable.me/install) or follow the [MCP setup guide](./mcp/setup).

## Build with your agent

Copy this into your coding agent:

> Add Proofable to this project using the official quickstart. Use the existing authentication stack. Verify the integration before changing anything else.

## What Proofable does

- **Verify:** Run a supported identity, ownership, risk, or permission check.
- **Reuse:** Save the result as proof instead of repeating the check.
- **Enforce:** Require proof before access, payment, or an agent action.
