## Using Proofable

<Steps>
  <Step title="Sign in">
    Sign in at [proofable.me](https://proofable.me/verify?intent=login). Your profile holds your agents, proofs, permissions, and connections.

    **Free to start · Pro $19.99/mo · Enterprise custom**

    [View pricing →](/pricing)
  </Step>
  <Step title="Connect an agent to Proofable">
    If an AI assistant or agent uses Proofable for you, connect it to the hosted MCP server at `https://mcp.proofable.me/mcp`.

    <ConnectHosts />

  </Step>
  <Step title="Or build with Proofable">
    Add Proofable to an app, backend, agent runtime, or automation.

    <Tabs>
      <Tab title="TypeScript">
        ```bash
        npm install @proofable/sdk
        ```

        Check an agent's permission before a tool runs:

        ```ts
        import fs from 'node:fs';
        import { evaluateRuntimeAction } from '@proofable/sdk/runtime-mount';

        // Written by: npx -y @proofable/sdk mount <agentId> --apply <host>
        const bundle = JSON.parse(fs.readFileSync('.proofable/mount.json', 'utf8'));
        const decision = evaluateRuntimeAction(bundle, 'send_message', { irreversible: true });

        if (!decision.allowed) {
          throw new Error(`${decision.code}: ${decision.message}`);
        }
        ```

        Check a proof before access:

        ```ts
        import { ProofableClient } from '@proofable/sdk';

        const client = new ProofableClient();
        const result = await client.gateCheck({
          gateId: 'gate_your-app-name',
          address: user.accountAddress,
        });

        if (result.data?.gate?.allRequiredSatisfied !== true) {
          // Send the user to verify first
        }
        ```

        [JavaScript SDK reference](/sdks/javascript)
      </Tab>
      <Tab title="REST API">
        Use the HTTP API from any language or backend.

        ```text
        https://api.proofable.me
        ```

        ```bash
        curl "https://api.proofable.me/api/v1/proofs/check?gateId=gate_your-app-name&address=0x..."
        ```

        `data.gate.allRequiredSatisfied` is `true` when the visitor's proofs meet every requirement. [HTTP API reference](/api/overview)
      </Tab>
      <Tab title="CLI">
        ```bash
        npx -y @proofable/sdk setup
        ```

        Writes the Proofable MCP entry for Cursor, Claude Code, Codex, and VS Code. Then confirm the live connection:

        ```bash
        npx -y @proofable/sdk doctor --live
        ```

        [CLI reference](/sdks/cli)
      </Tab>
    </Tabs>
  </Step>
</Steps>
