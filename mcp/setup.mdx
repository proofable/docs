## From a terminal

```bash
npx -y @proofable/sdk setup
```

The CLI registers the hosted server and installs the workflow skill for supported clients. It reuses existing plugin entries. [CLI reference](/sdks/cli)

## Troubleshooting

- No tools appear. Restart your client after adding Proofable.
- Session expired. Run `npx -y @proofable/sdk refresh` before signing in again.
- Confirm the connection. Run `npx -y @proofable/sdk doctor --live`.
- Two Proofable entries. Keep one plugin or manual server entry. Running setup again removes a leftover entry when the plugin already supplies it.
- Need agent context in a project. Run `npx -y @proofable/sdk mount <agentId> --apply <host>`. See [Load agent context](/agents/runtime-mount).
- Search-only endpoint. Use `https://mcp.proofable.me/mcp`. The docs MCP endpoint only searches documentation.

To disconnect, run `npx -y @proofable/sdk disconnect`. [MCP tools](/mcp/tools) and [authentication](/mcp/auth) cover the full reference.
