---
title: Update or comment on a proof (`proofable_proofs_update`)
description: Use a proof ID to edit its details or leave feedback.
icon: pen
---

With the **`qHash`** in hand, edit the title or tags, or leave one vote or comment per call. Omit **`walletAddress`** when signed in.

## What changes

The title helps people recognize a proof. Tags are short values for retrieval with [**`proofable_proofs_get`**](./proofs-get). Votes and comments are feedback, not proof that a claim is correct or approved. Owners can vote on their own proofs. Private proof feedback is owner-only; public proof feedback requires sign-in. These actions do not change verified content, verifier results, or ownership. Visibility is a separate control: [Proofs](../proofs).

| Auth | Visibility |
|------|------------|
| None | Not available |
| Bearer | Metadata changes require ownership. Public proof feedback requires sign-in; private proof feedback requires ownership ([Auth](./auth)). |

## Input

```json
{
  "qHash": "0x...",
  "vote": "up"
}
```

| Field | Notes |
|-------|-------|
| `qHash` | Required. The proof ID to update or review. |
| `title` | New title. Omit to keep, `null` to clear. |
| `addTags` | Exact retrieval tags to add. |
| `removeTags` | Exact existing tags to remove. |
| `vote` | `up`, `down`, or `clear` to change your vote. Proof owners can vote on their own proofs. |
| `comment` | Add a comment. Use `parentId` to reply to an existing comment. |
| `parentId` | Optional comment ID to reply to. Requires `comment`. |
| `walletAddress` | Optional owner wallet. Omit when signed in to use the current account. |

Send one kind of update per call: metadata, one vote, or one comment.

## Response

Returns the proof ID and the result of the update, vote, or comment.

## Read it back

Use **`proofable_proofs_get`** with `qHash` and `includeComments: true` to read comments. Use `tags` for an exact tag match, `tagPrefix` for a namespace, or `tagContains` for tag text.

## Assistant output

Do:

```txt
Proofable: Feedback saved on this proof.
```

Avoid raw JSON or claiming votes establish correctness or approval.
