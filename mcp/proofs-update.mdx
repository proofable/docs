With the **`qHash`** in hand, edit the title, tags or visibility, correct a record, or leave one vote or comment per call. Omit **`walletAddress`** when signed in.

## What changes

The title helps people recognize a proof. Tags are short values for retrieval with [**`proofable_proofs_get`**](./proofs-get). Votes and comments are feedback signals; they never mark a claim correct or approved. A proof's body is the record as written and never changes. Correct one by writing its successor. `supersede` creates a copy with the new title or body, names the old proof as superseded, and retires it from current listings while the old proof stays readable by ID. Verified content, verifier results and ownership stay unchanged. Owners can vote on their own proofs.

| Auth | Access |
|------|------------|
| None | Not available |
| Bearer | Title, tags and visibility changes require ownership. Public proof feedback requires sign-in; private proof feedback requires ownership ([Auth](./auth)). |

## Input

```json
{
  "qHash": "0x...",
  "vote": "up"
}
```

| Field | Notes |
|-------|-------|
| `qHash` | Required. The proof ID to update or review. |
| `title` | New title. Omit to keep, `null` to clear. |
| `addTags` | Exact retrieval tags to add. |
| `removeTags` | Exact existing tags to remove. |
| `visibility` | `public` (discoverable), `unlisted` (link-only), or `private` (owner-only). Only the owner's own session can change it. Making a shared proof private revokes public access. |
| `disclosePortableProof` | Allow the full portable envelope on anonymous reads of this public proof by ID. Default `false`. |
| `vote` | `up`, `down`, or `clear` to change your vote. |
| `comment` | Add a comment. Use `parentId` to reply to an existing comment. |
| `supersede` | Correct this record with `{ "title": "…", "content": "…", "tags": ["…"] }`. Omit `title` or `content` to carry the current value forward. Send it alone in a call; the proof must use the ownership check only. |
| `parentId` | Optional comment ID to reply to. Requires `comment`. |
| `walletAddress` | Optional owner wallet. Omit when signed in to use the current account. |

Send one kind of update per call, either metadata, one supersede, one vote, or one comment. A delegated agent needs the `manage_proofs` action.

## Response

Returns the proof ID and the result of the update, vote, or comment. A supersede returns the new proof ID in `qHash` and the replaced one in `previousQHash`.

## Read it back

Use **`proofable_proofs_get`** with `qHash` and `includeComments: true` to read comments. Use `tags` for an exact tag match, `tagPrefix` for a namespace, or `tagContains` for tag text.

## Assistant output

```txt
Proofable: Feedback saved on this proof.
```

Avoid raw JSON, and never present votes as proof of correctness or approval.
