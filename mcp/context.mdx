Call **`proofable_context`** once at the start of a Proofable MCP session. When the connection is signed in, the same call returns the profile.

## What it returns

| Field | Use |
|-------|-----|
| `setup.mcpEndpoint` | The hosted MCP endpoint in use (`https://mcp.proofable.me/mcp`) |
| `sessionWallet` | Signed-in account address. Omit `wallet` on later tools when signed in |
| `contextIndex` | Up to three title-and-proof-ID references per scope |
| `profileContext` | Signed-in profile, agents, and `profileSummary.proofsSummary` (totals, verifier counts, recent proof references) |
| `runtimeContract` | Recommended tool order and stopping conditions |
| `verifierSummary` | Compact list of available verifiers |

Agent entries omit instructions and skill bodies, and tool descriptions stay in MCP `tools/list`. Use **`proofable_proofs_get`** for full records or a known proof body, and **`proofable_agent_mount`** to load one agent.

When signed in, let account-based tools use the current profile. Ownership proofs finish with **`proofable_verify`**. Share a hosted link only when a tool returns one for an outside login, payment, or a different account.
