Checks the agent on your profile before agent work. Pass the signed-in account from **`proofable_context`** as **`agentWallet`**, or the dedicated spend account if you created one.

A signed-in-profile agent needs verified identity. A separate spend account also needs signed limits.

| State | Meaning |
|-------|---------|
| **`linked: true`** | Identity and required permissions are on file. Continue. |
| **`link_required`** | A step is missing. Open **`hostedVerifyUrl`** or follow **`nextSteps`**; **`missingVerifiers`** names the step. |

## Input

```json
{ "agentWallet": "0x…", "agentId": "data-analyst" }
```

| Field | Notes |
|-------|-------|
| `agentWallet` | Required. The agent account |
| `agentId` | Required when one account hosts several agents |
| `principal` | Optional owner account or DID. Omit when the signed-in profile is the owner |
| `identityQHash` | Optional identity proof ID the agent just signed, so the owner can link an identity no permission names yet |

The tool changes nothing. To grant or change authority, use [`proofable_agent_create`](./agent-create) or `proofable_verify` with `agent-delegation`. See [Agents](/agents) and [Discover agents](../agents/named-agent-card).
