## Output

An array of live verifier **IDs** (strings), e.g. `["ownership-basic", "proof-of-human", ...]`. Use it to confirm which verifiers exist before building a request.

For input fields and schemas per verifier, see the [Verifiers](../verification/verifiers) pages and the JSON schemas in [`verifiers/schemas/`](https://github.com/proofable/docs/tree/main/verifiers/schemas), or call `GET /api/v1/verification/verifiers` for the full metadata response.
