`proofable_context` already returns a compact `verifierSummary`. Call **`proofable_verifiers_catalog`** when you need the full list and each check's required inputs. It runs without sign-in.

## Input

```json
{}
```

## Output

| Field | Contents |
|-------|----------|
| `verifiers` | Live verifier IDs, e.g. `["ownership-basic", "proof-of-human", ...]` |
| `metadata` | Per-verifier details keyed by ID: required fields, data schema, and flow type |

The same data is available from `GET /api/v1/verification/verifiers`. Per-check guides are in [Verifiers](../verification/verifiers), and the JSON schemas are in [`verifiers/schemas/`](https://github.com/proofable/docs/tree/main/verifiers/schemas).
