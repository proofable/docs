Call **`proofable_context`** once, then pick the tool for the job. A signed-in connection gets every tool on this page on every plan. Each call runs on your credits and within the permissions on your profile, and `tools/list` returns the set your connection can call.

| Job | Tool | What it does |
|---|---|---|
| Start | `proofable_context` | Signed-in profile, what you can verify, and the recommended flow. |
| List what you can verify | `proofable_verifiers_catalog` | Required inputs and supported networks. |
| Reuse a proof | `proofable_proofs_check` | Read-only. Reports whether a current proof already satisfies the request. |
| Finish what's missing | `proofable_verify_or_guide` | Reuses a proof, or returns the next step. |
| Create a proof in-session | `proofable_verify` | Creates the proof when the signed-in account can authorize it. |
| Prepare an outside signature | `proofable_verify_prepare` | Returns the exact signing string and timestamp; creates no proof. |
| Submit an outside signature | `proofable_verify_submit` | Creates the proof from a signed prepared check. |
| Read a proof | `proofable_proofs_get` | Current proof records and status. |
| Update or review a proof | `proofable_proofs_update` | Change title/tags, vote, or comment on the same proof. |
| Revoke a proof | `proofable_proof_revoke` | Removes a proof from public access. |
| Create or import an agent | `proofable_agent_create` | Links the agent to your profile. Optional separate spend account and controls. Pass an existing account address for dedicated spend. |
| Confirm the agent is ready | `proofable_agent_link` | Identity and the permissions that account needs. |
| Load the agent | `proofable_agent_mount` | Identity, permissions, skills, and current settings. |
| List agents | `proofable_agents_list` | Agent identities and delegations on the profile. |

## Research and browsing tools

These reach the public web. Use search and fetch for reading, and the browser only when a page needs a click, JavaScript, or a visual check.

| Job | Tool | What it does |
|---|---|---|
| Search the web | `proofable_web_search` | Structured results; optionally retrieves each page as text. |
| Read a page | `proofable_url_fetch` | Clean page text from a public URL. Private and metadata hosts are refused. |
| Operate a page | `proofable_browser` | Open, observe, click, type, screenshot and read console in an isolated session. |
| Call a connected app | `proofable_composio_search` / `proofable_composio_execute` | Find and run an action on Gmail, Drive, GitHub, Slack and similar apps. |

An action that would create an external side effect needs approval first. Actions that reach another business system go through `proofable_composio_execute`, which is permissioned.

Prefer your own client's search, page fetch and browser. These are here for a client that has none, and each call is metered: `proofable_web_search` and `proofable_url_fetch` record 1 credit, and `proofable_composio_execute` records 2. The browser runs on your hosted computer, charged by the minute. [Pricing](/pricing) lists the rates.

## Job tools

| Job | Tool | What it does |
|---|---|---|
| Start work | `proofable_job_create` | Run agent work now or on a schedule. |
| List work | `proofable_job_list` | List jobs available to the signed-in profile. |
| Inspect work | `proofable_job_get` | Read one job and its latest run state. |
| Approve a step | `proofable_job_decide` | Approve or deny a run that is waiting for approval. |
| Stop work | `proofable_job_cancel` | Cancel a run or recurring schedule. |

A run started here costs what [Jobs](/jobs) lists for a run started in Proofable.

## Notes and saved tools

| Job | Tool | What it does |
|---|---|---|
| Save a session note | `proofable_session_receipt_create` / `proofable_session_receipt_append` | Private receipt in your account; append adds to an existing one. |
| Create or update a tool | `proofable_skill_tool_create_or_update` | A JavaScript tool or skill, run only when you or an agent invokes it. |

## Saved keys

| Job | Tool | What it does |
|---|---|---|
| List saved keys | `proofable_secret_list` | Names and update times. Never a value. |
| Remove a saved key | `proofable_secret_revoke` | Deletes a saved key by proof ID. |
| Call a provider with a saved key | `proofable_capability_call` | Proofable sends the request with your key and returns the provider's answer. The key never reaches the client. |

Save a key on [Secrets](./secrets), not through a tool. A key typed into an AI app's conversation has already been disclosed to that app.

## Remote MCP servers

Save another MCP server on your profile and run its tools through Proofable, so each call carries your permissions and leaves a receipt.

| Job | Tool | What it does |
|---|---|---|
| Save, list or remove a server | `proofable_mcp_connection_create` / `proofable_mcp_connections_list` / `proofable_mcp_connection_delete` | The server's URL and headers, stored encrypted on your profile. |
| Use a server | `proofable_mcp_tools_list` / `proofable_mcp_tool_execute` | List its tools and run one. Each run records 1 credit. Private and metadata hosts are refused. |

| Topic | Detail |
|-------|--------|
| Session context | Call **`proofable_context`** first. After Connect it includes the signed-in profile. |
| Create in-session | **`proofable_verify`** when signed in and ownership can finish here. |
| Interactive | **`proofable_verify_or_guide`** reuses a proof, then continues with **`proofable_verify`** or returns a hosted link for an outside login, payment, or different account. |

## Field names

| Tool | Address field | Verifiers / filters |
|------|---------------|---------------------|
| `proofable_proofs_check` | `wallet` | `verifiers` |
| `proofable_verify`, `proofable_verify_prepare`, `proofable_verify_submit`, `proofable_verify_or_guide` | `walletAddress` | `verifierIds` |
| `proofable_proofs_get` | `identifier` | optional `tags` (comma-separated proof tags) |
| `proofable_proofs_update` | `qHash` (proof ID) | optional metadata, `vote`, or `comment` |

Wallet address in native format, or `did:pkh:…`. Delegated reads: **`agentWallet`** on **`proofable_proofs_get`** (**`x-agent-wallet`** on the API).

## Order

| Phase | Calls |
|-------|-------|
| Default | Connect → **`proofable_context`** → **`proofable_agent_link`** for agents → **`proofable_verify_or_guide`** before sensitive actions |
| Project agent | **`proofable_agent_mount`** or `proofable mount <agentId> --apply <host>` in the repo |
| Details | **`proofable_proofs_get`** for proof records, tags, delegated context, and proof fields |
| Fallback | **`proofable_verify_or_guide`** only when something is missing |
| Catalog | **`proofable_verifiers_catalog`** only when you need raw schemas beyond the compact `verifierSummary` in `proofable_context` |

Same flow as [Overview](./overview).
