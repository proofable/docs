18 tools, every plan, every client. ChatGPT serves 8 of them: `proofable_context`, `proofable_proofs_check`, `proofable_verify_or_guide`, `proofable_proofs_get`, `proofable_proofs_update` and the three agent tools. Each call runs on your credits and within your profile permissions.

## Trust

| Job | Tool | What it does |
|---|---|---|
| Start | `proofable_context` | Your profile, proofs, agents, permissions and credits. Call once. |
| Get trusted | `proofable_verify_or_guide` | Reuses a qualifying proof, or returns the one next step. |
| See every check | `proofable_verifiers_catalog` | Check IDs, inputs and networks. |
| Gate on a proof | `proofable_proofs_check` | Pass or fail. Never returns content. |
| Prove it | `proofable_verify` | Runs the checks and saves the proof. Also grants agent permissions. |
| Sign elsewhere | `proofable_verify_prepare`, then `proofable_verify_submit` | Another wallet signs; the proof saves when it passes. |
| Read | `proofable_proofs_get` | One proof by ID, or search by text, tag or check. |
| Edit or review | `proofable_proofs_update` | Title, tags, visibility, a supersede correction, vote or comment. |
| Revoke | `proofable_proof_revoke` | Immediate, everywhere. Revoking a delegation ends that agent's permission. |

## Agents

| Job | Tool | What it does |
|---|---|---|
| Add an agent | `proofable_agent_create` | Its own ID, owned by you, with the limits you set. |
| Check a permission | `proofable_agent_link` | What the agent may do right now. |
| Run as an agent | `proofable_agent_mount` | Loads its identity, permissions and skills into your client. |

## Jobs

| Job | Tool | What it does |
|---|---|---|
| Hand off work | `proofable_job_create` | Now, later or on a schedule. Uses the browser, search and connected apps the agent's permission allows. |
| Follow it | `proofable_job_get` | Status, result and any pending approval. |
| See all runs | `proofable_job_list` | Filter by status, or `scheduled` for recurring series. |
| Approve | `proofable_job_decide` | Approve or deny a run waiting on you. |
| Stop | `proofable_job_cancel` | A run or a recurring series. |

A run costs what [Jobs](/jobs) lists. Keys are saved on your profile ([Secrets](./secrets)), never in a chat.

## Field names

| Tool | Address field | Verifiers / filters |
|------|---------------|---------------------|
| `proofable_proofs_check` | `wallet` | `verifiers` |
| `proofable_verify`, `proofable_verify_prepare`, `proofable_verify_submit`, `proofable_verify_or_guide` | `walletAddress` | `verifierIds` |
| `proofable_proofs_get` | `identifier` | optional `tags` (array or comma-separated string) |
| `proofable_proofs_update` | `qHash` (proof ID) | optional metadata, visibility, `supersede`, `vote`, or `comment` |

Wallet address in native format, or `did:pkh:…`. Delegated reads: **`agentWallet`** on **`proofable_proofs_get`** (**`x-agent-wallet`** on the API).

## Order

| Phase | Calls |
|-------|-------|
| Default | **`proofable_context`**, then **`proofable_verify_or_guide`** before a sensitive action |
| Agents | **`proofable_agent_link`** to check, **`proofable_agent_mount`** to run as it (or `proofable mount <agentId> --apply <host>` in the repo) |
| Work | **`proofable_job_create`**, then **`proofable_job_get`** |
| Details | **`proofable_proofs_get`** for records, tags and delegated context |
| Catalog | **`proofable_verifiers_catalog`** when you need inputs beyond the `verifierSummary` in `proofable_context` |
