**Yes/no lookup only.** Use it before you verify again or open a hosted handoff. It creates no proofs, opens no hosted flows, and returns no proof content. To read a body, start from the `proofable_context` context index and call **`proofable_proofs_get`** with a known proof ID and `include=content`.

Private proofs count only for the signed-in account ([Auth](./auth)). Signed-in owners omit `wallet` and get `{ eligible, matchedCount }` from their own proofs without paying. Public third-party lookups may return `payment_required`.

If **`eligible`** is true, continue. If false, call **`proofable_verify_or_guide`**. When signed in, ownership proofs continue with **`proofable_verify`**.

## Input

Uses **`wallet`** (not `walletAddress`):

```json
{
  "wallet": "0x...",
  "verifiers": ["ownership-basic"],
  "requireAll": true
}
```

`requireAll` defaults to `false`, which accepts any one listed verifier. Optional `minCount` requires at least N matching proofs. Optional `gateId` scopes a hosted listing. Optional `handle` and `namespace` filter handle-based verifiers.

## Output

`eligible`, `matchedCount`, `success`.
