The official Proofable CLI ships in [`@proofable/sdk`](https://www.npmjs.com/package/@proofable/sdk) and runs without a permanent install.

```bash
npx -y @proofable/sdk
```

| Command | Purpose |
|---------|---------|
| `npx -y @proofable/sdk setup` | Register hosted MCP on the local client |
| `npx -y @proofable/sdk doctor --live` | Confirm the live connection |
| `npx -y @proofable/sdk auth` | Sign in when the host needs a profile session |
| `npx -y @proofable/sdk import <path\|url>` | Inspect a package, repo, card, or runtime link |
| `npx -y @proofable/sdk mount <agentId> --apply <host>` | Write the mount bundle for `cursor`, `claude`, `codex`, `hermes`, `openclaw`, or `opencode` |

For the shorter `proofable setup`, `proofable doctor --live`, and `proofable auth`, install once with `npm install -g @proofable/sdk`.

HTTP agents read [Proofable OpenAPI](https://api.proofable.me/openapi.json). Assistants connect to [Proofable MCP](https://mcp.proofable.me/mcp).
