Default strategy: **`reuse-or-create`**. Every `VerifyGate` prop is in [VerifyGate](../widgets/verifygate).

## Privacy

`client.verify()` is an advanced server or controlled-signing path. `VerifyGate` opens **Hosted Verify** for checks that cannot finish inside your app. Full matrix: [Security](../security)

| Option | When |
|--------|------|
| `privacyLevel: 'private'` | Default; owner or authorized access for private reads |
| `privacyLevel: 'public'` | Public reuse without owner auth; pair with `publicDisplay` |
| `publicDisplay: false` | Unlisted. Anyone with the proof ID can read it |
| `publicDisplay: true` | Listed / discoverable (needs `public`) |

`storeOriginalContent` and these visibility options apply to `client.verify()`.

## Reuse-first

```jsx
<VerifyGate
  gate={[{ verifierId: 'proof-of-human' }]}
  strategy="reuse-or-create"
>
  <Protected />
</VerifyGate>
```

## Fresh

For high-stakes actions, force a new proof:

```jsx
<VerifyGate strategy="fresh" gate={[{ verifierId: 'proof-of-human' }]}>
  <Protected />
</VerifyGate>
```

## Read-only gate

```jsx
<VerifyGate strategy="reuse" gate={[{ verifierId: 'proof-of-human' }]}>
  <Protected />
</VerifyGate>
```

## Hosted interactive

Hand off to `/verify` for the missing verifier:

```jsx
<VerifyGate
  gate={[{ verifierId: 'proof-of-human' }]}
  hostedCheckoutUrl="https://proofable.me/verify"
/>
```

[Hosted Verify](../verification/hosted)

## Server check

Prefer **`gateCheck`** over pulling full proofs for every decision:

```javascript
const result = await client.gateCheck({
  gate: [{ verifierId: 'proof-of-human' }],
  subject: { accountId: user.accountAddress },
});

if (!result.satisfied) throw new Error('Verification required');
```
