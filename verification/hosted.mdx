Send users to `https://proofable.me/verify` for sign-in, proof of human, social and work accounts, or listing checkout. Passkey, OAuth, and wallet steps all run there.

## What runs here

| Query | The user completes | You get |
|---|---|---|
| `intent=login` | Passkey sign-in, with an optional wallet attach | A Proofable session |
| `gateId` | Listing checkout. Wallet steps appear only when the published gate requires them. | A proof |
| `verifiers` or `preset` | The named checks. See [Presets](/verification/presets). | A proof |

Social and work-account checks run their OAuth step inside the verifier: [ownership-social](/verification/ownership-social), [ownership-org-oauth](/verification/ownership-org-oauth).

## Parameters

| Param | Use |
| --- | --- |
| `intent=login` | Sign-in only |
| `returnUrl` | Absolute `https://` URL in your app to return to. Validated before redirect. |
| `returnTo` | A path on `proofable.me`, such as `/profile`. `getHostedCheckoutUrl` does not set it. |
| `connect=1` | With `intent=login`, starts wallet connect on load |
| `gateId` | Published gate |
| `mode=popup` | Run as a popup. Requires `origin`. |
| `origin` | Opener origin for `postMessage` |
| `appId` | Attribution for a server-registered app. Ignored with `gateId`. |

## Redirect examples

Checkout or proof in your app:

```javascript
import { getHostedCheckoutUrl } from '@proofable/sdk';

window.location.href = getHostedCheckoutUrl({
  gateId: 'gate_your-app-name',
  returnUrl: 'https://app.example.com/auth/callback',
});
```

After the redirect, read the proof ID from the `qHash` field in your callback URL.

Sign in, then return to your app:

```javascript
import { getHostedCheckoutUrl } from '@proofable/sdk';

window.location.href = getHostedCheckoutUrl({
  intent: 'login',
  returnUrl: 'https://app.example.com/auth/after-login',
});
```

Stay on `proofable.me`:

```txt
https://proofable.me/verify?intent=login&returnTo=/profile
```

`proofable.me/login` redirects to `/verify?intent=login` with a validated `returnTo`.

## Popup

Open with `mode: 'popup'` and `origin: window.location.origin`.

| Flow | Opener listens for |
|------|-------------------|
| Verification or gate | `neus_checkout_done`, with `qHash` when a proof was created |
| `intent=login` | `neus_login_complete` |
