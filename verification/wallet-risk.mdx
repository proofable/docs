**Verifier ID:** `wallet-risk`

Lookup. Proofable checks the wallet with Webacy before payments, fraud-sensitive actions, and high-risk onboarding.

## Fields

| Field | Required | Notes |
|------|----------|-------|
| `walletAddress` | Yes | Wallet to assess |
| `provider` | No | `webacy` (default) |
| `chain` or `chainId` | No | Chain context: `eth`, `base`, `bsc`, `pol`, `opt`, `arb`, `sol`, `ton`, `sei`, `sui`, `btc`, `stellar` |

## Example

```json
{
  "walletAddress": "0x...",
  "chain": "base"
}
```

Full schema: [`wallet-risk.json`](https://github.com/proofable/docs/blob/main/verifiers/schemas/wallet-risk.json).
