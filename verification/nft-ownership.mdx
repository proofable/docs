**Verifier ID:** `nft-ownership`

Lookup. Proofable reads on-chain ownership.

## Fields

| Field | Required | Notes |
|------|----------|-------|
| `contractAddress` | Yes | NFT contract or mint |
| `tokenId` | Yes | Token ID |
| `chainId` or `chain` | Yes | Chain ID or CAIP-2 chain |
| `tokenType` | No | `erc721` (default) or `erc1155` |
| `ownerAddress` | No | Wallet to check; defaults to the signer |
| `blockNumber` | No | Check ownership at a specific block |

## Example

```json
{
  "contractAddress": "0x...",
  "tokenId": "1",
  "chainId": 8453
}
```

For high-value access, require a recent proof with `sinceDays` on `gateCheck`, or run a fresh check.

Full schema: [`nft-ownership.json`](https://github.com/proofable/docs/blob/main/verifiers/schemas/nft-ownership.json).
