**Verifier ID:** `ownership-pseudonym`

Instant. The user claims a portable public handle with one wallet signature. The [account ownership guide](/verification/accounts#verified-handles) covers badges and server checks.

## Fields

| Field | Required | Notes |
|------|----------|-------|
| `pseudonymId` | Yes | Handle, 3 to 32 characters, pattern `^[a-z0-9][a-z0-9._-]{1,30}[a-z0-9]$` |
| `namespace` | No | Defaults to `proofable`. Legacy `neus` writes remap to `proofable`; existing `neus:<handle>` proofs still resolve. |
| `displayName` | No | Human-readable label |
| `metadata` | No | Object for app-specific attributes |

## Example

```json
{
  "pseudonymId": "alice123",
  "displayName": "Alice"
}
```

## Expiry

The proof includes an `expiresAt`. Re-verify before it lapses.

Full schema: [`ownership-pseudonym.json`](https://github.com/proofable/docs/blob/main/verifiers/schemas/ownership-pseudonym.json).
