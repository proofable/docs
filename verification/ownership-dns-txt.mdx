**Verifier ID:** `ownership-dns-txt`

Lookup. Proofable reads the TXT record at `_proofable.<domain>` and compares it to the wallet address that signs the check. Records published under the earlier `_neus.<domain>` name still verify. The [domain guide](./domain) walks through setup.

## DNS record

Create a TXT record named `_proofable` on the domain. For `example.com`, the lookup is `_proofable.example.com`.

| Value | When it matches |
|--------|------------------|
| `wallet=<address>` | Default. The address must match the signing wallet. Write Ethereum addresses as lowercase `0x` plus 40 hex digits. |
| `wallet=eip155:<chainId>:<address>` | Only when the verification request passes a numeric `chainId` in its options. |

Only the `wallet=` prefix is read. For other networks, copy the address exactly as Proofable shows it, since some formats are case-sensitive.

## Fields

| Field | Required | Notes |
|------|----------|-------|
| `domain` | Yes | The hostname you control in DNS |
| `walletAddress` | No | Filled from the signing wallet. If you set it, it must match the signer. With neither, the check fails. |

## Example

```json
{
  "domain": "example.com"
}
```

Full schema: [`ownership-dns-txt.json`](https://github.com/proofable/docs/blob/main/verifiers/schemas/ownership-dns-txt.json).
