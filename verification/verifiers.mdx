## Types

| Type | What happens |
|---|---|
| Instant | The account signs during the session. |
| Interactive | The person completes a hosted step on Proofable. |
| Lookup | Proofable reads live on-chain, DNS, or provider state. |

## Bundles

Run several checks with `?verifiers=id1,id2`, or a named bundle with `?preset=`. [Presets](./presets) lists the bundles.

To add a check, [propose a verifier](./propose-a-verifier).
