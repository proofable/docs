**Verifier ID:** `token-holding`

Lookup. Proofable reads current token balances for balance-based access and membership tiers.

## Fields

| Field | Required | Notes |
|------|----------|-------|
| `contractAddress` | Yes | Token contract or mint |
| `minBalance` | Yes | Human-readable token amount, such as `"10.5"`. Converted with the token's on-chain decimals, not base units |
| `chainId` or `chain` | Yes | Chain ID or CAIP-2 chain |
| `ownerAddress` | No | Wallet to check; defaults to the signer |
| `blockNumber` | No | Check the balance at a specific block |

## Example

```json
{
  "contractAddress": "0x...",
  "minBalance": "100",
  "chainId": 8453
}
```

Full schema: [`token-holding.json`](https://github.com/proofable/docs/blob/main/verifiers/schemas/token-holding.json).
