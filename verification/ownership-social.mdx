**Verifier ID:** `ownership-social`

Confirm a person controls a social account, then reuse that result for trust pages, community gating, and linking a handle to a wallet or profile. OAuth runs on Proofable, so OAuth tokens never reach your app.

## Flow type

Interactive, hosted-only. The user authorizes the provider on Proofable and returns with a result. Your backend cannot submit this check directly, and it runs on its own, never combined with other checks in one request.

## Providers

Hosted Verify offers `discord`, `github`, `x`, and `linkedin`.

## The simplest path

Send the user to Hosted Verify, then read the proof back:

```text
https://proofable.me/verify?verifiers=ownership-social&returnUrl=https://app.example.com/verified
```

You get a proof ID in the `qHash` field. Store it and reuse it on later visits.

## Fields

| Field | Required | Notes |
|------|----------|-------|
| `provider` | Yes | The provider the user signed in with |
| `internalSocialToken` | Yes (direct submit) | Short-lived token the hosted OAuth step issues. Your app never creates it. |
| `walletAddress` | No | Subject override to bind the handle to a wallet |

Full schema: [`ownership-social.json`](https://github.com/proofable/docs/blob/main/verifiers/schemas/ownership-social.json).
