**Verifier ID:** `ownership-org-oauth`

Confirm a person belongs to an organization, then gate member-only apps, agents, tools, and partner portals. The person signs in with Google Workspace or Microsoft 365, or enters a one-time code sent to their work email, so organizations on any mail host can pass. Personal mail hosts such as Gmail, Outlook.com, and Yahoo never pass. Sign-in and codes run on Proofable through Hosted Verify or `VerifyGate`.

A person already signed in to Proofable with that work email confirms it in one click, with no new code.

## Flow type

Interactive, hosted-only. Your backend cannot submit this verifier directly, and it runs on its own, never combined with other checks in one request.

## The simplest path

```text
https://proofable.me/verify?verifiers=ownership-org-oauth&returnUrl=https://app.example.com/verified
```

You get a proof ID in the `qHash` field. Store and reuse it.

## Fields

| Field | Required | Notes |
|------|----------|-------|
| `provider` | Yes | `google`, `microsoft`, or `email` (a one-time code sent to the work address) |
| `internalSocialToken` | Yes (direct submit) | Short-lived token issued by the hosted sign-in or code step |
| `expectedOrgDomain` | No | Restrict the proof to one company domain such as `acme.com`. Omit it to accept any organization domain. |
| `walletAddress` | No | Subject override to bind membership to a wallet |

Full schema: [`ownership-org-oauth.json`](https://github.com/proofable/docs/blob/main/verifiers/schemas/ownership-org-oauth.json).
