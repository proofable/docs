**Verifier ID:** `contract-ownership`

Lookup. Proofable reads owner or admin authority on-chain.

## Fields

| Field | Required | Notes |
|------|----------|-------|
| `contractAddress` | Yes | EVM contract address |
| `chainId` | Yes | EVM chain ID |
| `method` | No | `owner`, `admin`, or `accessControl`. Omit to try all three in that order |
| `walletAddress` | No | Address to check; defaults to the signer |

## Example

```json
{
  "contractAddress": "0x...",
  "chainId": 8453,
  "method": "owner"
}
```

Full schema: [`contract-ownership.json`](https://github.com/proofable/docs/blob/main/verifiers/schemas/contract-ownership.json).
