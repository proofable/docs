**Verifier ID:** `proof-of-human`

Confirm a real person for sybil resistance, rewards, and trusted onboarding. ZKPassport runs the check, and the proof records privacy-preserving claims with an assurance level.

## Flow type

Interactive, hosted-only. The user completes the personhood step on Proofable and returns with a result. It runs on its own, never combined with other checks in one request.

## What you configure

| Field | Required | Notes |
|------|----------|-------|
| `provider` | No | `zkpassport` (default) |
| `scope` | No | Scope for the personhood identifier. Omit it to use the default. |

The hosted step returns the provider `proofs` and `queryResult` that a direct API submission carries. Use Hosted Verify or `VerifyGate` to produce them.

## Response fields

| Field | Visibility | Description |
|-------|-----------|-------------|
| `provider` | Public | Provider that verified, such as `zkpassport` |
| `assuranceLevel` | Public | `low`, `medium`, or `high` |
| `claims` | Public | Booleans such as `personhood_verified`, `age_verified`, and `facematch_verified` |
| `traits` | Public | Provider metadata: scope, domain, `verifiedAt` |
| `expiresAt` | Public | Expiry timestamp |

## Assurance levels

| Level | Criteria |
|-------|----------|
| `high` | Strict face match verified |
| `medium` | Non-strict face match, or a KYC bundle, verified |
| `low` | Personhood, age, or nationality claims only |
