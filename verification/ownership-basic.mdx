**Verifier ID:** `ownership-basic`

Instant. The owning wallet signs text or a reference, so anyone can later check who said it and what the exact text was. Use it for release notes, policy text, agent outputs, licensing claims, bounty submissions, and marketplace listings.

Proofs can be private, unlisted, or public. [Security](../security) covers the defaults.

## Fields

| Field | Required | Notes |
|-------|----------|-------|
| `owner` | Yes | Must match the signer wallet |
| `content` | No | Text to bind to the account, up to 50,000 characters |
| `reference` | No | Stable pointer `{ type, id }`, not a bare string |
| `contentHash` | No | A Proofable content hash (`0x` + 64 hex) returned by an earlier verification. A generic SHA-256 will not match. |
| `provenance` | No | Advisory human, AI, or mixed metadata |

Send at least one of `content`, `contentHash`, or `reference.id`.

To keep the exact text on the proof, leave the `storeOriginalContent` option on (the SDK default) and read it back from `proof.publicContent.content`. When only a hash or pointer was stored, readers see a resolution status such as `hash_only_not_recoverable` in place of the text.

### Example payload

```json
{
  "owner": "0x...",
  "content": "Release notes for v1.2",
  "reference": {
    "type": "url",
    "id": "https://example.com/releases/v1-2",
    "title": "Release notes v1.2"
  },
  "provenance": {
    "declaredKind": "mixed",
    "aiContext": {
      "generatorType": "agent",
      "provider": "Proofable",
      "model": "release-workflow",
      "runId": "release-v1-2"
    }
  }
}
```

## Verification links in hosted gates

A hosted gate can check live JSON from a URL the visitor submits. Add an output match such as `resolved.verified = true`. `/verify` reads JSON from the submitted URL, or its `.json` representation, and evaluates the returned fields.

```json
{
  "verifierId": "ownership-basic",
  "match": [
    { "path": "reference.type", "op": "eq", "value": "url" },
    { "path": "resolved.verified", "op": "eq", "value": "true" }
  ],
  "maxAgeMs": 300000
}
```

The visitor supplies only the URL. The gate owns the resolver rules and expected output. URL references without a `resolved.*` match are never fetched.

Full schema: [`ownership-basic.json`](https://github.com/proofable/docs/blob/main/verifiers/schemas/ownership-basic.json).
