[Add Proofable](../mcp/setup), finish the sign-in your client opens, then ask:

> Create agents research, writer, and ops on my Proofable profile. Give any of them a separate spend account if they need one. Set limits. Confirm they are ready.

## Set it up

<Steps>
  <Step title="Connect">
    Add `https://mcp.proofable.me/mcp`, then finish the sign-in your client opens.
  </Step>
  <Step title="Create each agent">
    **`proofable_agent_create`** per agent. Default is your signed-in profile. Pass an existing dedicated account address only when that agent needs its own spend account.
  </Step>
  <Step title="Confirm">
    **`proofable_agent_link`** until **`linked: true`**. Pass **`agentId`** on every link and mount call when one account hosts several agents.
  </Step>
</Steps>

Revoke one agent without touching the others.
