Measured on the live service and inside a real coding agent. Last measured October 17, 2026.

| Result | Measured on |
|---|---|
| Every action without current permission was refused before it ran | 8 cases on the live service |
| 4.8 ms per check | 98 decisions inside a coding agent |
| 4 ms to verify a record later, with no account and no AI model | A live record, checked offline |

## Refused before it runs

We tried each way an agent's permission can fail: revoked, expired, outside its scope, waiting on a
person who never answers, and revoked while a job runs. Valid permission ran normally. Each case is
a public signed record: [see all eight](/use-cases/authority-at-dispatch).

## 4.8 ms per check

Inside a real coding agent on five tasks, the check made 98 decisions and added 467 ms in
total. It refused nothing, so no task was stopped by it.

## Verifying later is free

Producing a result costs the work itself, 37 s here. Anyone can then verify its record offline
in 4 ms, with no account and no AI model.

## Verify it yourself

```sh
git clone https://github.com/proofable/docs
cd docs/public/evidence/aaif/authority-at-dispatch/2026-10-08-eight-case
sha256sum -c SHA256SUMS
npm install @proofable/sdk@0.1.6
node verify-portable-proofs.mjs
```

To run the cases on your own account, use the [reproduce kit](/use-cases/authority-at-dispatch#run-it-yourself).
