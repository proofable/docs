Proofable checks what an AI agent is allowed to do before it acts, and signs a record of every
decision that anyone can verify. Last measured 2026-10-17.

## Agents cannot act without current permission

On the live service, we tried each way an agent's permission can fail:

- the permission was revoked, or had expired
- the action was outside what the permission allows
- a person had to approve and never answered, or answered too late
- the permission was revoked while a job was running

Every action without current permission was refused before it ran. When permission was revoked
mid-job, the next action was refused and the record shows what had already happened. Two
controls with valid permission ran normally. All 8 cases behaved as specified, and each decision is a
public signed record: [see the eight cases](/use-cases/authority-at-dispatch). These records are
part of the [AAIF Identity & Trust working-group comparison](https://github.com/aaif/wg-identity-and-trust/issues/13).

## Each check adds 4.8 ms

Inside a real coding agent working on five tasks, the check made 98 decisions and added
4.8 ms to each, 467 ms in total. It refused nothing, so no task was stopped by it.

## Verifying a result later is free

Producing a result takes as long as the work, 37 s here. After that, anyone can verify
its signed record offline in 4 ms, with no account and no AI model.

## Verify it yourself

```sh
git clone https://github.com/proofable/docs
cd docs/public/evidence/aaif/authority-at-dispatch/2026-10-08-eight-case
sha256sum -c SHA256SUMS
npm install @proofable/sdk@0.1.6
node verify-portable-proofs.mjs
```

To run the eight cases on your own account, use the
[reproduce kit](/use-cases/authority-at-dispatch#run-it-yourself).
