Before an agent's job runs, Proofable checks that the agent holds current permission for it. If it
does not, the job is refused before anything runs. Every decision is a signed record anyone can open.

## The eight cases

Run on the live service on October 8, 2026. Each link opens the public record.

| Case | Result | Record |
|---|---|---|
| Permission granted | Ran and completed | [open](https://proofable.me/proof/0x64f293e61b826e03bd1de6564fc2db8cec0f50390bafc8bdf162ec9961262fca) |
| Action outside the permission | Refused before it ran | [open](https://proofable.me/proof/0xffdc0455b72732a8c6a31eb4e2861943b85dbc271fe2dfa8b18d0e85d2b33726) |
| Needs approval, approved | Held until approved, then ran | [open](https://proofable.me/proof/0xf80c5b1bcab2a3a4f14d4a8745200dffa987517eb78f4950cafbf6688f42384e) |
| Needs approval, nobody answers | Never ran; a late approval was refused | [open](https://proofable.me/proof/0x6c53cb0005c9dc30fde5bb1bd06860d74ae51790be3869a6605bfc9f71e01954) |
| Permission revoked | Refused; no job created | [open](https://proofable.me/proof/0x8a3e5ff89c8a86423bae61db96c9732f319a6f6cdb34f4bde560c90d25366c95) |
| Permission expired | Refused; no job created | [open](https://proofable.me/proof/0xf1880cba0876acc2364e31892b261a47299c0a70177b61b32d465fcd1b61447a) |
| Revoked permission reused | Refused every time | [open](https://proofable.me/proof/0x1d987781eb519337fa9e62043831ee187340f6e589f217b16b99ed98be5acfbc) |
| Permission revoked mid-job | The running step finished; the next one was refused | [open](https://proofable.me/proof/0x05ef986ee3817a6fd56b327b1de3523ab7f65c11c4ff386d34c16f93d11c0045) |

## Verify it yourself

Check all 15 signed records offline, with no account:

```sh
git clone https://github.com/proofable/docs
cd docs/public/evidence/aaif/authority-at-dispatch/2026-10-08-eight-case
sha256sum -c SHA256SUMS
npm install @proofable/sdk@0.1.6
node verify-portable-proofs.mjs
```

## Run it yourself

The [reproduce kit](https://github.com/proofable/docs/tree/main/public/evidence/aaif/authority-at-dispatch/reproduce)
runs the same eight cases on the live service under your own account, and the records it writes are
yours. Jobs need Pro. Reviewers get 30 days free: email [dev@proofable.me](mailto:dev@proofable.me)
with your account handle.

```sh
npm install
export PROOFABLE_ACCESS_KEY=npk_...
export AAD_OPERATOR="Your Organization"
node aad.mjs setup
node aad.mjs run
node aad.mjs verify runs/<run-id>
```
