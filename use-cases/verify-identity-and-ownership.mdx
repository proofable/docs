Confirm the subject first. Save the result as a proof. The next access decision reads that proof instead of collecting the same evidence again.

## Start with the check you need

| If you need | Start here |
|---|---|
| A real person | [Proof of human](/verification/proof-of-human) |
| A social or work account | [Linked social accounts](/verification/ownership-social) or [team and organization](/verification/ownership-org-oauth) |
| A domain or handle | [Domain ownership](/verification/ownership-dns-txt) or [username](/verification/ownership-pseudonym) |
| A wallet or on-chain asset | [Linked wallets](/verification/wallet-link), [NFT holder](/verification/nft-ownership), or [token balance](/verification/token-holding) |
| An agent | [Agent identity](/agents/agent-identity) |

The full catalog, including risk and content checks, is on [Verify](/verification).

**Interactive** checks run on Proofable: passkey, OAuth, or a personhood step. **Instant** checks finish when the account signs. **Lookup** checks read live state.

## Start a check

<Tabs>
  <Tab title="Hosted">
    Send people to Proofable. They complete the check there and return with a proof ID.

    ```text
    https://proofable.me/verify?verifiers=ownership-org-oauth&returnUrl=https://app.example.com/verified
    ```

    Read the proof ID from the `qHash` field on your return URL.
  </Tab>
  <Tab title="SDK">
    ```js
    import { getHostedCheckoutUrl } from '@proofable/sdk';

    window.location.assign(
      getHostedCheckoutUrl({
        verifiers: ['ownership-social'],
        returnUrl: 'https://app.example.com/verified',
      }),
    );
    ```
  </Tab>
  <Tab title="MCP">
    ```text
    Verify my GitHub account with Proofable. Reuse a current proof if I already have one.
    ```

    The assistant reuses a current proof first, or returns the one hosted step you need to finish.
  </Tab>
</Tabs>

## Require it before access

Define the required checks in your app, use `gateCheck` on your server, and show `VerifyGate` only when something is missing. [Gate access](/use-cases/gate-access)
