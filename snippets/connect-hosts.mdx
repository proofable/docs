  <Tab title="Claude Code">
    Run these in Claude Code to install the server and workflow skills:

    ```text
    /plugin marketplace add proofable/mcp
    /plugin install proofable-mcp@proofable
    ```

    Run `/mcp`, select Proofable, and complete sign-in.
  </Tab>
  <Tab title="Claude">
    [Open Claude](https://claude.ai/)

    In Customize, open Connectors and add a custom connector with this URL:

    ```text
    https://mcp.proofable.me/mcp
    ```

    Choose Connect and complete sign-in. On Team and Enterprise, an owner adds the connector first.
  </Tab>
  <Tab title="Codex">
    Run in your terminal:

    ```bash
    npx -y @proofable/sdk setup --client codex
    codex mcp login proofable
    ```

    Codex opens browser sign-in.
  </Tab>
  <Tab title="ChatGPT">
    [Open ChatGPT](https://chatgpt.com/)

    Enable developer mode in Settings, add a custom MCP connection with the URL below, and complete the sign-in ChatGPT opens. Your plan or workspace policy must allow custom connections.

    ```text
    https://mcp.proofable.me/mcp
    ```
  </Tab>
  <Tab title="VS Code">
    [Add Proofable to VS Code](vscode:mcp/install?%7B%22name%22%3A%22proofable%22%2C%22type%22%3A%22http%22%2C%22url%22%3A%22https%3A%2F%2Fmcp.proofable.me%2Fmcp%22%7D)

    Start Proofable from MCP: List Servers and complete the sign-in VS Code opens.
  </Tab>
  <Tab title="Other clients">
    Add this URL in your client's MCP settings, then complete its sign-in:

    ```text
    https://mcp.proofable.me/mcp
    ```

    For terminal clients, ask your agent to follow the setup prompt above. [Authentication](/mcp/auth) covers clients that require a server key.
  </Tab>
