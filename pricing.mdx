Credits pay for checks, saved proofs, hosted AI, job runs and the hosted computer. Sign-in is always free, and the SDK and API work on every plan.

## Plans

| Plan | Price | Credits per month | API throughput | Start |
|---|---|---|---|---|
| **Free** | Free | 500 | 60 per minute | [Start free](https://proofable.me/verify?intent=login) |
| **Pro** | $29.99 a month | 15,000 | 240 per minute | [Start Pro](https://proofable.me/profile?tab=credits) |

**Pro adds** the hosted AI [Advanced tier](/jobs) at twice the credit rate, a larger monthly credit allowance and 4× the API throughput.

**Enterprise adds** a 500,000-credit monthly allowance and 10× API throughput, set by agreement with the Proofable team. [Enterprise](/enterprise)

## Included on every plan

Hosted sign-in and profile, Hosted Verify and reusable proofs, agent identity and permission proofs, the Proof Graph, agent composing with your own model key, hosted AI on the Default tier, jobs in the background or on a schedule, and the hosted computer.

## What a job costs

| Part | Credits |
|---|---|
| Each run, on any model or key | 1 |
| Hosted AI, Default tier | 1 per 1,000 tokens |
| Hosted AI, Advanced tier (Pro and above) | 2 per 1,000 tokens |
| Your own model key | 0 for tokens |
| Hosted computer or job machine | 2 per vCPU for each started minute; the standard browser machine is 2 vCPUs, so 4 a minute |

## What a tool call costs

Signing in, checking a saved proof, and reading your own profile, proofs, agents and jobs are free. Creating a proof is charged as a check below. The calls that reach another service are metered per call:

| Call | Credits |
|---|---|
| Web search (`proofable_web_search`) | 1 |
| Read a page (`proofable_url_fetch`) | 1 |
| Run a connected-app action (`proofable_composio_execute`) | 2 |
| Run a tool on a saved remote MCP server (`proofable_mcp_tool_execute`) | 1 |
| Call a provider with your saved key (`proofable_capability_call`) | 0 |

A job started over MCP is charged as a job above, and operating a page with `proofable_browser` is charged as the hosted computer above. [MCP tools](/mcp/tools) lists every tool a connection carries.

## What checks cost

One credit lists at $0.0025.

| Action | Credits | Price |
|---|---|---|
| Sign in | 0 | Free |
| Check an existing proof | 0 | Free |
| Create and save a new proof | 4+ | From $0.01 |

Checking a saved proof is free and rate-limited per plan. You pay only when you create a new proof. Its
cost depends on the verifier, and the price is shown before a billable verification runs.
`GET https://api.proofable.me/api/v1/payments/pricing` returns the credit cost of every check.

## Top-ups

Buy credits at any time from [your profile](https://proofable.me/profile?tab=credits). Card top-ups start at 200 credits. Suggested packs are 5,000 and 10,000 credits. Purchased credits never expire.

## Who pays

| Option | Who pays | Use it for |
|---|---|---|
| Sponsored usage | Your app | Keep checks inside your product. |
| Listing checkout | The user | Paid content, services, or access. |
| Pay per call | The caller | Agents and APIs that pay for each request with [x402](/gates/pay-per-call). |

### Charge visitors

Turn on visitor checkout in the gate's pricing step. For card payments, connect a payout account once under [Payouts](https://proofable.me/profile?tab=credits). Until payouts are connected, paid gates accept USDC only. Payment runs after verification by default. On card sales, the seller receives 90% and Proofable keeps 10%. Proofable pays the card processing. [Gate checkout](/gates/checkout)

## Agent setup

Agent setup creates two separately signed proofs. Each is billed to its signer unless a validated sponsor or pay-per-call proof applies.

| Step | Default payer |
|---|---|
| The agent signs `agent-identity` | The agent's account |
| The owner signs `agent-delegation` | The approving account |
| Your server signs with its own profile | Your builder profile |
| A valid sponsor grant | The sponsoring organization |
| A valid pay-per-call proof | The caller that paid |

## When credits run out

Billable calls return `402` with a quote. Add credits, or pay for the call with [x402](/gates/pay-per-call) and retry with the `PAYMENT-SIGNATURE` header.

Per-plan request limits are in [Rate limits](/api/rate-limits).
